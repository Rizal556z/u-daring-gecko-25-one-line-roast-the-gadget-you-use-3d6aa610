## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The line

**My fitness tracker cheered my 10,000 steps, nine thousand of which were just me pacing while the microwave reheated my lunch.**

The tracker cannot tell exercise from impatient waiting — and
celebrates both the same way.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-test python3 main.py
cat /tmp/roast-test/entry.txt
```
